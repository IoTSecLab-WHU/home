# 武汉大学物联网安全实验室网站

## 文件结构

```
index.html        网站页面（样式和显示逻辑，平时不用改）
data/             全部内容，每个栏目一个文件
  lab.json          实验室名称、简介、首页数字、联系方式
  news.json         新闻动态
  research.json     研究方向
  team.json         负责人、研究人员、博士后、学生
  projects.json     科研项目
  output.json       论文、奖励、专利、著作
  training.json     毕业生去向、培养方式、校友寄语
  join.json         招聘岗位
images/           照片（通过后台上传）
.pages.yml        后台表单配置
```

## 成员怎么更新内容（推荐：网页后台）

1. 打开 https://app.pagescms.org ，用自己的 GitHub 账号登录。
2. 选择本仓库，左侧菜单就是网站的各个栏目。
3. 例如发新闻：点「新闻动态」→「添加」→ 填写日期、类别、标题、摘要 →「保存」。
4. 保存后 1–2 分钟，网站自动更新。

每一次修改都会留下记录（谁、什么时候、改了什么），改错了可以在 GitHub 的 History 里恢复。

## 分工建议

| 栏目 | 负责人 |
|---|---|
| 新闻动态、加入我们 | 实验室秘书 / 高年级博士生 |
| 科研成果（论文） | 每位同学发表后自己添加 |
| 科研团队、人才培养 | 每年 9 月、6 月由秘书统一更新 |
| 基本信息、研究方向 | 负责人审定 |

## 本地预览（可选）

直接双击 index.html 看不到内容（浏览器不允许网页从本地读取数据文件）。在本文件夹里运行：

```
python -m http.server 8000
```

然后浏览器打开 http://localhost:8000 。

## 照片和个人主页

- 在后台「科研团队」里，每位老师、博士后和学生都有「照片」和「个人主页链接」两个输入框。
- 照片直接在后台上传，会保存到 `images/people/`。正方形或竖版证件照效果最好，400×400 像素左右即可。没有照片时显示名字的后两个字。
- 填了个人主页链接的人，名字会带下划线和 ↗，点击后在新窗口打开主页；不填则名字只是普通文字。
